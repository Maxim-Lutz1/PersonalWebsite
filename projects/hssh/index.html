hssh.

A lightweight interactive SSH host manager for Linux, written in Rust. Manage your SSH connections directly from the terminal.

View on GitHub ↗

01 / ABOUT THE PROJECT

CLI TOOL / RUST

SSH, simplified.

hssh is a small interactive SSH host manager designed to make managing remote connections easier and more convenient. Instead of remembering hostnames and repeatedly typing SSH commands, simply select a saved device from an interactive terminal interface.

02 / FEATURES

01 / INTERACTIVE

Host selection

Browse saved SSH hosts using an interactive terminal interface with arrow-key navigation.

02 / MANAGEMENT

Host management

Add, list and remove saved SSH devices directly from the command line.

03 / DIRECT ACCESS

Quick connections

Connect directly to a saved host using its alias.

04 / SECURITY

OpenSSH integration

Authentication and host verification are handled by OpenSSH. hssh does not store passwords.

03 / INSTALLATION

REQUIREMENTS

Rust & OpenSSH

hssh requires Rust, Cargo and OpenSSH. On Arch Linux, install the dependencies with: 

sudo pacman -S rust openssh

INSTALL

Build from source

Clone the repository and install hssh using Cargo. 

git clone https://github.com/Maxim-Lutz1/hssh.git
cd hssh
cargo install --path .

04 / USAGE

COMMANDS

Getting started

Manage and connect to your saved SSH hosts using simple commands. 

hssh add       # Add a device
hssh           # Open interactive host selection
hssh list      # List saved devices
hssh remove    # Remove a device
hssh mypi      # Connect to the "mypi" alias
